# Project: NEXUS — Modern SaaS Admin Dashboard

Act as a senior UI/UX designer, frontend architect, and React developer.

Your task is to design and develop a professional, modern, responsive SaaS administration dashboard called **NEXUS**.

## 1. Design direction

Create a premium dashboard inspired by modern SaaS products such as Linear, Vercel, Stripe, and modern analytics platforms.

The interface should feel:
- Modern and professional
- Minimalist but visually rich
- Clean and well-organized
- Premium and polished
- Easy to navigate
- Responsive on desktop, tablet, and mobile

Use a consistent design system throughout the application.

## 2. Technology stack

Use:
- React with Vite
- TypeScript
- Tailwind CSS
- React Router
- Recharts for data visualization
- Lucide React for icons

Use reusable React components and a clean folder structure.

## 3. Color system

Use a sophisticated dark interface.

- Main background: #0B0D12
- Sidebar: #11141B
- Card background: #171B24
- Primary accent: #8B5CF6
- Secondary accent: #06B6D4
- Main text: #F8FAFC
- Secondary text: #94A3B8
- Borders: subtle dark grey

Use gradients sparingly. Avoid excessive glowing effects.

## 4. Layout

Create a fixed or collapsible sidebar containing:

- NEXUS logo
- Overview
- Analytics
- Projects
- Users
- Transactions
- Messages
- Settings

Add a top navigation bar with:

- Search field
- Notification icon
- Help icon
- User avatar
- User profile dropdown

The dashboard content should adapt to the available screen width.

## 5. Dashboard overview

Create four statistic cards:

1. Total Revenue — $48,290
2. Total Users — 12,840
3. Active Projects — 248
4. Conversion Rate — 8.42%

Each card should include:
- Relevant icon
- Main statistic
- Percentage change
- Comparison with the previous month
- Small visual trend indicator

## 6. Analytics section

Create a large revenue analytics chart using Recharts.

Include:
- Monthly revenue
- User growth
- Interactive tooltips
- Chart legend
- Time filters: 7 days, 30 days, 90 days, 12 months

Add a second chart showing user distribution by category.

Use realistic demonstration data.

## 7. Recent activity

Create a recent activity table with:

- User avatar
- User name
- Activity
- Date
- Status

Use status badges such as:
- Completed
- Pending
- Failed

Include at least six realistic demonstration records.

## 8. Additional UI components

Include:
- Recent projects section
- Notifications panel
- Quick action buttons
- Profile dropdown
- Search interface
- Theme toggle if practical

## 9. Interactions

The dashboard must not be a static screenshot.

Implement:
- Working sidebar navigation
- Active navigation states
- Collapsible sidebar
- Functional dropdowns
- Interactive chart filters
- Search filtering for table records
- Responsive mobile navigation
- Theme toggle if implemented

Use local mock data. Do not require a backend or external API.

## 10. Quality requirements

- Use reusable components.
- Avoid duplicated code.
- Maintain consistent spacing and typography.
- Use proper semantic HTML.
- Include accessible labels and keyboard-friendly controls.
- Add hover, focus, and transition states.
- Ensure there are no broken imports or missing dependencies.
- Make the interface responsive.

## 11. Development workflow

Before implementation:

1. Inspect the existing repository.
2. Explain the proposed folder structure.
3. Identify the required dependencies.
4. Present a short implementation plan.

Then implement the dashboard in logical stages.

After implementation:

1. Run the available build and type checks.
2. Fix errors.
3. Verify the main interactions.
4. Summarize the files created and features implemented.

Do not replace existing project files unnecessarily. Ask before destructive operations.

**Final objective:** Deliver a polished, functional, responsive SaaS admin dashboard that looks like a professionally designed commercial product.
